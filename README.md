# ELITE STRIKE

Protótipo jogável de combate 2D feito em Canvas puro, pensado para dispositivos Android de entrada e computadores.

## Abrir o jogo
Abra [index.html](./index.html) em um navegador moderno. Para publicar como site, habilite GitHub Pages nas configurações do repositório (Settings → Pages → Deploy from a branch → main → /(root)).

## Build 0.1
- Duas facções selecionáveis: Batalhão e Terroristas.
- Classes: Assalto, Sniper, Suporte e Médico (ajustes simples de atributos/munição).
- Combate offline contra bots, munição, recarga, vida e condição de vitória/derrota.
- Canvas 2D sem frameworks, CDN, dependências ou downloads de assets.
- Resolução de render limitada a 1x e arte geométrica simples para aliviar celulares fracos.

## Controles
- PC: WASD/setas para movimentar, mouse para mirar, clique esquerdo para disparar, R para recarregar.
- Mobile: toque/arraste na tela para movimentar e mirar; botão FIRE para disparar e RELOAD para recarregar.

## Limitações atuais
É um protótipo inicial: perspectiva top-down 2D, bots básicos, sem multiplayer online, sem modelos 3D e sem sistema persistente de progressão. A classe Médico ainda não tem habilidade especial. O projeto vai evoluir por builds.
